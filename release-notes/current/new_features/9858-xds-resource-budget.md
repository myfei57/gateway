Added an optional `xdsServer.resourceBudget` to the EnvoyGateway configuration that bounds candidate xDS snapshots before publication: per-type-URL resource counts, protobuf-serialized bytes, per-resource byte size and reference edges are metered on the final deduplicated resources (including extension-appended resources), over-budget generations are rejected with a Gateway/Route-attributed report while Envoy keeps serving the last good snapshot, and secret content never appears in the report.
